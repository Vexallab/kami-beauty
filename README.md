# Kami Beauty

Сайт салона маникюра «Ками Бьюти» в Москве. 

## Что внутри

7 страниц:

- `index.html` — главная
- `prices.html` — прайс-лист + калькулятор примерной стоимости
- `portfolio.html` — портфолио работ (масонри-сетка с фильтрами по категориям)
- `reviews.html` — отзывы
- `contacts.html` — контакты и форма записи
- `privacy.html` — политика обработки персональных данных
- `404.html` — страница не найдена, с поиском по разделам сайта

## Стек

Vanilla HTML/CSS/JS. Из библиотек — только:

- **GSAP + ScrollTrigger** — анимации (появление секций, наклон карточек, счётчики), самостоятельно захостены в `js/vendor/`, без CDN
- **Lenis** — инерционный плавный скролл всей страницы (`js/smooth-scroll.js`)

Всё остальное — свой код: маска телефона, вкладки прайса, масонри-раскладка галерей, орбита видео на главной, калькулятор цены, поиск на 404.

## Как запустить локально

Просто открыть `index.html` через `file://` не получится — сломается форма записи (FormSubmit не работает с локальных файлов) и Service Worker. Нужен обычный HTTP-сервер:

```
python -m http.server 8000
```

и открыть `http://localhost:8000`.

Для отдельной проверки страницы 404 (с правильным HTTP-статусом 404, как это будет у реального хостинга) есть `_dev_404_server.py` — временный скрипт, его можно удалить в любой момент, на сам сайт он не влияет.

## Форма записи

Работает через [FormSubmit.co](https://formsubmit.co/) — без своего бэкенда. Есть нюанс: их AJAX-эндпоинт не умеет доставлять вложения (референс-фото), поэтому в `js/main.js` два пути отправки — обычный AJAX для заявки без фото, и нативный POST-сабмит с редиректом обратно на страницу, если фото приложено. Плюс honeypot-поле против ботов.

## Service Worker

`sw.js` кеширует статику (HTML/CSS/JS) для оффлайн-доступа и повторных визитов. Важно: при любом изменении файлов из `PRECACHE_URLS` нужно бампнуть `CACHE_NAME`, иначе браузер будет отдавать старую версию из кеша.

## Шрифты

`Playfair Display` для заголовков (у `Bodoni Moda`, к слову, нет кириллицы — на неё легко напороться, если решите поменять шрифт обратно).
